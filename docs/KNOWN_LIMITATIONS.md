# 已知限制

“解放”的核心架构已经支持统一 Resume JSON、栏目遍历、字段匹配、动态数组、文件上传、任务状态和悬浮面板，但通用 DOM 自动化无法保证覆盖所有学校自研组件。安全策略是：证据不足时不填、不上传、不点击。

## 栏目导航

1. Generic Adapter 会扫描常见侧栏、顶栏、menu、tab 以及 Ant Design、Element Plus 等菜单节点，但非常规 Canvas 导航、图片热区或脚本私有路由可能无法识别。
2. SPA 的 `pushState`、`replaceState`、hash 和局部 DOM 更新可通过 URL/MutationObserver/DOM 稳定等待处理；如果栏目点击触发完整页面刷新，临时注入、DOM 引用和内存授权会失效。用户必须重新点击扩展、重新扫描并再次预览确认后继续。
3. 完整刷新后可读取安全的任务摘要，但不能无条件恢复写操作或文件授权。这是有意的用户授权边界。
4. 如果用户在任务运行中手动切换页面、登录过期、出现确认弹窗或网站网络错误，引擎可能暂停或记录当前栏目失败，不能保证自动恢复。
5. 跨源 iframe 无法由 `activeTab` 的主文档通用处理；同样不处理关闭的 Shadow DOM、Canvas 和图片表单。

## 字段匹配与控件

6. Generic Adapter 不能保证所有定制 Select、级联选择、树选择、日期弹窗、富文本、虚拟列表和经过混淆的表单组件都能操作。
7. 标准 input/select/radio/checkbox 和常见 React/Vue 风格状态可用原生 setter 与事件链处理，但个别框架可能依赖私有事件、内部 store 或特殊键盘序列，需要 Site Adapter。
8. “名称”“类别”“时间”等弱标签在多个 Resume 路径间有歧义时会标记 `NEEDS_CONFIRMATION`，不会为了提高覆盖率而猜填。
9. 字段处于只读、禁用、不可见、未挂载或被弹窗遮挡时不会强行修改。
10. 默认只填空白字段。网页值和 JSON 不同时会报告冲突；即使开启覆盖，也不能改写网站禁止编辑的字段。
11. 日期可在常见年月/年月日格式间转换，但无法可靠打开的日期组件会留给人工处理。

## 动态数组

12. 重复组优先使用表格行、表单项容器、共同父级和坐标分组。高度虚拟化、只有当前一行挂载或组间没有可区分结构的页面可能无法建立一一映射。
13. 动态新增必须看到 DOM 变化且实际组数增加。只修改服务器状态、仅改变不可见缓存或按钮点击后无新增组时，会在超时/最大次数后停止。
14. 插件不自动删除现有组。JSON 条数少于网页组数时，多余网页内容保持不变。
15. 原“奖励情况（本科期间）”的时间、地点、内容回退适配继续保留；其他站点若结构特殊，仍需根据脱敏诊断增加小型 Adapter。

## 文件与材料库

16. 材料库只接受 PDF、JPG/JPEG、PNG、DOCX，单文件上限 50 MB。浏览器可用配额、内存和消息大小因设备而异，大文件即使低于 50 MB 也可能失败。
17. 通用上传以可访问的 `<input type="file">` 为核心。某些自定义上传组件没有可用 input、只接受操作系统文件选择器、要求裁剪/签名/分片或在关闭 Shadow DOM 中运行，需要 Site Adapter 或人工上传。
18. 页面格式、大小和数量限制只能根据 DOM 中可解析的提示与 input 属性判断；写在图片、弹窗或服务器响应中的限制无法预先确认。
19. 文件已进入网页 `FileList` 只证明浏览器端交接成功。学校服务器是否上传完成、扫描通过、生成缩略图或保存成功，仍需人工查看网页状态。
20. “其他附件”或多个材料候选分数接近时不会自动上传。用户可在悬浮面板选择或跳过。
21. Resume JSON 导出不包含 IndexedDB Blob。换电脑、换浏览器配置或重装后需要重新导入材料并更新 fileId。
22. 材料预览由浏览器打开临时 Blob URL，可能受弹窗设置或浏览器对 DOCX 的预览能力限制。
23. 为防止授权重放，同一材料在同一次任务中只允许被授权读取一次；若同一文件确实要放入多个上传框，需要重新预览并启动新任务。

## 保存、提交与报告

24. 自动暂存默认关闭。开启后也只考虑明确的“保存/暂存/保存本页/保存当前信息”；按钮语义不清、包含下一步/提交/审核等词时不会点击。
25. “保存并下一步”不会自动点击，即使站点把它当作普通保存。
26. 最终提交、提交申请、确认报名、提交审核等操作永久禁止，不能通过设置或 Site Adapter 开启。
27. 报告通过 DOM 回读判断字段和 FileList 状态，无法证明学校后端已经持久化。每个栏目和最终提交前都必须人工核对。
28. 关闭 Popup 不影响当前文档中的任务；关闭悬浮面板只隐藏 UI。但浏览器结束标签页、扩展重载或整页刷新会结束当前内存任务。

## 权限、诊断与浏览器

29. 扩展只在用户点击后使用 `activeTab` 注入当前页，没有长期站点权限，因此不能无人值守跨任意标签页运行。
30. Chrome/Edge 内部页、扩展商店、PDF 内置查看器等受保护页面禁止脚本注入。
31. 诊断会程序化排除字段值和敏感内容，但学校 DOM 命名或标题仍可能包含业务信息；分享前必须人工检查。
32. 保研本地模式不提供 AI 回退。通用规则解析或匹配不足时会停止或要求人工确认。
33. 材料上传和自动暂存会触发当前学校网页自身的网络行为；扩展无法替代用户了解学校网站的隐私政策和服务状态。

## 出现问题时

1. 停在失败栏目，不要继续反复点击。
2. 打开 Popup 或悬浮面板，点击“诊断当前栏目”。
3. 复制或下载脱敏诊断 JSON，分享前人工检查。
4. 根据真实 DOM 在 `src/mappings/` 补充明确别名，或在 `config/site-adapters.json` / `chrome.storage.local.siteAdapterConfigs` 增加最小选择器覆盖。
5. 为新规则增加 fixture、单元测试和端到端安全测试。

详细开发流程见 [网站适配器开发说明](ADAPTERS.md)。
